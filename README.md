# Focus Quality Prediction Model

## Overview

This machine learning project predicts **task completion quality** based on personal, environmental, and cognitive factors such as age, role, task type, background noise, fatigue, and focus duration. The model is built using **XGBoost Regressor** and evaluates performance using **Mean Absolute Error (MAE)**.

---

## Features

* Data preprocessing with pandas
* One-hot encoding of categorical variables
* Train-test split for evaluation
* Regression model using XGBoost
* Accuracy measurement using MAE
* Feature importance visualization

---

## Technologies Used

* Python
* Pandas
* Scikit-learn
* XGBoost
